## 使用限制

- 指定的 `gbeitc.shx`、`gbcbig.shx` 缺失，文字实际使用 Noto Serif SC 替代。打开 DWG 前，请先安装交付包中的字体。PDF 已嵌入字体。指定 SHX 样式仅保留定义，未验证实际渲染。
- DWG 为真实的 AC1015 / DWG 2000 文件，经过回读和原生实体修改、保存、重新读取检查；未在 AutoCAD 2022 中实际打开、另存或打印验收。
- 标题栏按低分辨率截图及常用布局重建，不是截图的逐格复刻。

详细操作见[使用说明与检查记录](./使用说明与检查记录.txt)，检查结果见[验证记录](./dwg-validation.json)，四个主文件的 SHA-256 见[文件校验](./文件校验.json)。
